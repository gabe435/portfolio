# Portfólio Acadêmico Digital — DSM FATEC SJC

Repositório oficial do portfólio acadêmico pessoal desenvolvido para a disciplina de Desenvolvimento de Software Multiplataforma (DSM) da FATEC São José dos Campos (Prof. Jessen Vidal). O projeto tem como objetivo centralizar a apresentação de competências técnicas, histórico acadêmico e os projetos integradores desenvolvidos ao longo do curso.

## Estrutura do Repositório

O projeto foi construído utilizando tecnologias nativas da Web, priorizando desempenho, responsividade e organização semântica:

* `index.html`: Arquivo principal contendo a estruturação semântica de todas as seções obrigatórias (Apresentação, Projetos API, Projetos Acadêmicos e Profissionais, Informações Curriculares e Contato).
* `style.css`: Folha de estilos personalizada utilizando CSS Grid e Flexbox para garantir a adaptação fluida em diferentes resoluções de tela (mobile e desktop).
* `assets/`: Diretório reservado para recursos estáticos e mídias do portfólio.

---

## Seções Principais

1. **Apresentação Pessoal:** Resumo profissional, objetivos acadêmicos, áreas de interesse e links diretos para perfis de contato.
2. **Projetos API (Aprendizagem por Projetos Integrados):** Exposição detalhada do projeto desenvolvido semestralmente em equipe com parceiros do mercado.
   * **Projeto Atual (1º Semestre):** *Crédito Inclusivo* (Equipe Kurumin), voltado ao processamento e visualização de dados públicos de crédito e inadimplência do Banco Central e IBGE.
3. **Projetos Profissionais e Pessoais:** Exibição de trabalhos práticos como a aplicação web *Pace Run Academy*, rotinas de automação em Bash/Linux e a experiência em operações de e-commerce e marketplaces (*GHR Commerce*).
4. **Informações Curriculares:** Histórico de formação acadêmica, stack tecnológica organizada (hard skills), competências interpessoais (soft skills) e cursos complementares.
5. **Contato:** Canais de comunicação direta e links para repositórios no GitHub e perfil no LinkedIn.
